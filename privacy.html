Privacy Policy

Last updated: November 3, 2026

This policy describes Kitsune Studio's personal, locally operated YouTube upload integration.

1. Information accessed through YouTube

When you choose to connect a YouTube account, Kitsune Studio uses Google OAuth 2.0 and requests https://www.googleapis.com/auth/youtube.upload. This permission allows the application to upload videos to the YouTube channel authorized by the account owner. The application does not request your Google password. For an upload you initiate, it processes the media file and upload information that you provide, such as title, description and visibility.

2. Purposes of access

Kitsune Studio uses YouTube authorization and upload data for the purpose of user-directed video publishing. It is not intended to access Gmail, contacts, or other unrelated Google services. The application does not use Google user data for advertising or profiling.

3. Local processing, storage and retention

The YouTube authorization flow completes through a locally operated application. OAuth credentials and refresh tokens may be retained within the local application environment to maintain an authorized session and to make upload requests. Local project files may remain on your device until removed. This public informational website does not accept or store OAuth credentials, media files or user project content. Local storage and removal procedures should be verified against the installed application's actual behavior before public deployment.

4. Third-party sharing and website technologies

Kitsune Studio sends authorized requests and the selected uploaded content to Google/YouTube API Services to perform video uploads. It does not sell Google user data. This informational website contains no analytics scripts, advertising pixels, contact forms or embedded trackers. The website itself may be subject to routine hosting infrastructure logs operated by GitHub Pages.

5. Control and revocation

You can disconnect YouTube from Kitsune Studio and revoke its access in Google Account permissions. Revocation stops future authorized API access, and authorization credentials and stored Google API data associated with revoked access should be deleted promptly as required by applicable YouTube API rules. For support identifying or removing any local authorization data, contact the developer using the address below.

6. Security

Keep the local application's OAuth authorization files and tokens private. Do not publish client credential JSON files, tokens or project secrets in public GitHub repositories. This informational site is separate from the application's local authorization callback and does not receive sign-in credentials.

7. Google and YouTube policies

Kitsune Studio uses YouTube API Services. The Google Privacy Policy and YouTube Terms of Service also apply to use of these services. Kitsune Studio's use of Google user data is intended to be limited to the user-facing features authorized in the app.

8. Updates and contact

When data-handling practices change, this policy must be updated accordingly. For questions about your privacy or local authorization, email veluna.music.contact@gmail.com.
